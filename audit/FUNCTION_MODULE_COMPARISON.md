# EconAtlas 新旧功能模块核对（2026-08-14）

## 核对结论

旧版的 16 个比赛功能模块已全部恢复为独立入口，没有再以“功能合并”为理由删除任何原模块。新版只对入口进行分类，并补充“平台总览”“系统运行”两个辅助页面；辅助页面不计入、也不替代原有比赛功能。

## 功能分类与恢复状态

| 分类 | 原模块 | 当前实现与数据依据 |
|---|---|---|
| 数据服务 | 指标查询 | 独立入口；按国家和指标查询、绘制趋势并展示明细，默认排除预测记录 |

| 数据服务 | JSON输出 | 独立入口；调用 `/query` 生成比赛要求的标准 JSON，不再并入 API 页面 |
| 数据服务 | 数据资产目录 | 独立入口；读取真实资产聚合，展示范围、来源与有效观测量 |
| 数据服务 | API服务中心 | 独立入口；列出真实可调用端点，并可打开 FastAPI 文档 |
| 质量治理 | 数据质量 | 独立入口；读取质量检查、覆盖率、一致性和异常值文件 |

| 智能应用 | 智能报告 | 独立入口；生成并下载 PDF、Markdown、JSON 和 CSV 报告 |

## 新增辅助页面

- 平台总览：汇总当前已发布数据规模，并单独披露预测情景数量。
- 系统运行：读取 `/system-status`，展示数据库、API、DeepSeek 配置和更新状态。

这两个页面用于降低评委理解成本，不改变比赛原功能清单。

## 数据时间边界

- “当前标准观测”“国家”“指标”“来源”“最新日期”只统计 `observation_type != 'forecast'`。
- `/query`、指标查询、JSON 输出、智能分析和智能报告默认排除预测值；仅显式传入 `include_forecast=true` 时才允许查询预测情景。
- 预测记录继续作为独立资产保存，不伪装成截至当前日期已发布的事实数据。
- 质量、风险和报告展示采用同一当前数据边界，避免未来年份进入当前结论。
