# EconAtlas 新旧功能模块核对（2026-08-14）

## 核对结论

旧版包含 16 个可见模块。统一管理面板第一次改版将其压缩为 10 个入口，但压缩过程中错误地把“风险预警”和“智能报告”降级成了静态说明，并让若干旧功能失去独立入口。本次修复遵循两条原则：入口可以合并，计算与查询能力不能丢失；尚未实现的能力不能用静态卡片伪装为已完成。

## 逐项对应

| 旧版模块 | 当前归属 | 状态与原因 |
|---|---|---|
| 智能问答 | 智能问答 | 保留；改为 DeepSeek 通用问答 + EconAtlas 数据检索，删除内部会话侧栏 |
| 指标查询 | 指标中心、API 服务 | 合并；标准目录可检索，时间序列由 `/query` 提供 |
| 指标字典 | 指标中心 | 合并；展示标准代码、名称、单位与观测量 |
| 数据质量 | 数据质量 | 保留；读取真实质量检查文件 |
| JSON 输出 | API 服务 | 合并；查询与报告接口均提供 JSON |
| 一致性分析 | 数据质量、风险预警 | 合并；读取真实多源一致性报告 |
| 治理驾驶舱 | 平台总览、数据治理 | 合并；规模总览与治理规则分开展示 |
| 指标血缘 | 数据治理、数据资产 | 暂时合并展示来源字段；独立可视化入口待恢复 |
| 治理规则 | 数据治理 | 保留；展示实际执行的标准化和语义隔离规则 |
| API 服务中心 | API 服务 | 保留；列出真实可调用端点 |
| 数据资产目录 | 数据资产 | 保留；默认排除预测情景，显示真实资产聚合结果 |
| 风险预警 | 风险预警 | 已恢复；读取质量、一致性和异常观测结果，不再是占位文字 |
| 智能分析 | 智能报告 | 合并；报告中生成趋势、统计与来源说明 |
| 智能报告 | 智能报告 | 已恢复；可生成并下载 Markdown、JSON、CSV |
| 资产评级 | 尚无独立入口 | 当前版本缺失；旧版基于完整性、覆盖度、来源、规模和新鲜度评级，后续应恢复 |
| 指标对齐审核 | 尚无独立入口 | 当前版本缺失；旧版读取对齐候选并支持人工复核展示，后续应恢复 |

## 数据时间边界

- “当前标准观测”“国家”“指标”“来源”“最新日期”只统计 `observation_type != forecast`。
- 预测记录仍保存在数据库中，作为独立预测情景资产，不进入当前数据总量。
- 智能报告明确排除预测记录。
- 截至 2026-08-14，库内预测记录为 IMF 2027—2031 年情景数据；它们不应被描述为当前已发布事实。
